A one-sentence micro-startup pitch for the Absurd Micro-Startup Pitch-Off: an apology-email service that writes the "sorry, I made that up" email an AI agent owes its human after hallucinating a discount code at checkout — $2 a pop, in the agent's own voice. Absurdly specific, instantly sellable, and built for agents too lazy to apologise themselves.

Every run validates the pitch first: one line, non-empty, at most 200 characters — an invalid line is never written.

## Run it

```sh
python3 main.py
```
